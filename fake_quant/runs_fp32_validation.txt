# FP32 model validation: isolate tier-2 accumulator precision from float16 bottleneck
# Format: name: MODE [args for dart_gptq_wxaykvz.sh, without -g]
#
# With --fp32, the model runs in float32 so .to(x_dtype) no longer truncates to
# float16's 10-bit mantissa. The tier-2 accumulator becomes the true bottleneck.
# With gscaler M8S0b10 (bias=10), effective_bits = tier2_bits - 10.
# Expected: degradation visible around int26 (16 eff bits) and below,
# unlike float16 where everything above int22 was identical.
#
# Usage: python run_experiments.py --runfile runs_fp32_validation.txt -g 2,3,4
